# feat: รองรับไฟล์ CSV หลายแบบ แจ้งแถวที่ข้อมูลไม่ครบ และปรับหน้าตาหน้าสรุป

ยังไม่ได้ไฟล์ CSV ตัวอย่างจากผู้ประเมิน PR นี้จึงทำให้ระบบอ่านไฟล์ที่ save จาก Excel ได้หลายแบบ แถวที่ข้อมูลผิดหรือไม่ครบจะไม่ทำให้ตัวเลขผิดแบบเงียบ ๆ แต่จะขึ้นคำเตือนให้ผู้จัดการตรวจ พร้อมปรับหน้าเว็บให้อ่านง่ายขึ้นสำหรับคนที่ไม่ใช่สาย IT ขอบเขตและ AC8–AC11 อยู่ใน `intent.md`

## การอ่านไฟล์

- `src/csv.ts`: รับหัวคอลัมน์ไทยหรืออังกฤษ ไม่มีคอลัมน์รหัสก็ได้ วันที่แบบ `23/11/2569` (ค.ศ. หรือ พ.ศ.) เวลาแบบ `8:05`, `08.05` และ `08:05:00` ช่องที่ครอบด้วย `"..."` แถวที่วันที่อ่านไม่ออกจะถูกย้ายไปเป็นคำเตือน และ error บอกชื่อคอลัมน์เป็นภาษาไทย
- `src/types.ts`: เพิ่ม `ParseResult` กับ `RowWarning` และเพิ่ม `warnings` ใน `WeeklySummary`

## การคำนวณ

- `src/summary.ts`: คิดเป็นรายวัน วันที่ลงเวลาหลายรอบจะคิด OT จากชั่วโมงรวมของวัน และนับสายครั้งเดียว แถวที่ไม่มีเวลาเข้าหรือออก หรือเวลาออกก่อนเวลาเข้า ไม่ถูกนับชั่วโมงและขึ้นคำเตือน ไฟล์ที่เกิน 7 วันขึ้นคำเตือน และภาพรวมแสดงวันที่แบบไทย

## หน้าเว็บ

- `src/main.ts`, `src/style.css`, `index.html`: กรอบลากวางไฟล์ บอกคอลัมน์ที่ต้องมี แถบชื่อไฟล์พร้อมปุ่มเปลี่ยนไฟล์ ภาพรวมแยกสีตามความหมาย กล่องคำเตือนสีเหลือง ตารางที่ใช้ป้ายสีกับค่ามาสายและ OT และหน้าจอมือถือที่เห็นครบทุกคอลัมน์

## วิธีทดสอบ

1. `npm install && npm test` ต้องเขียว 22/22
2. `npm run dev` แล้วกด "ลองด้วยไฟล์ตัวอย่าง" ตัวเลขต้องตรงกับตารางใน README
3. ลองวางไฟล์ที่ไม่มีเวลาออกบางแถว ต้องเห็นกล่องคำเตือนสีเหลืองบอกชื่อและวันที่
