# หลักฐาน TDD: เทสต์แดงก่อน แล้วค่อยเขียว

งานนี้ทำ TDD 3 รอบ ทุกรอบ commit เทสต์ตอนยังแดงก่อน แล้วค่อย commit โค้ดที่ทำให้เขียว

| รอบ | Commit เทสต์ (แดง)                                                            | Commit โค้ด (เขียว)                                                             | ผล                     |
| --- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ---------------------- |
| 1   | `9e8948e` test: add failing tests for weekly attendance summary              | `c5cb53d` feat: summarize weekly attendance per employee from csv             | แดง 8/8 → เขียว 8/8     |
| 2   | `c1afa32` test: add failing tests for flexible csv input and incomplete rows | `8f27294` feat: accept common csv formats and flag incomplete attendance rows | แดง 13/22 → เขียว 22/22 |
| 3   | `f9eea46` test: expect thai dates and no late count on reversed times        | `27a0b08` fix: show thai dates and skip late count on reversed clock times    | แดง 4/22 → เขียว 22/22  |

ลองเองได้: `git checkout <commit เทสต์> && npm test` จะเห็นแดง แล้ว `git checkout <commit โค้ด> && npm test` จะเห็นเขียว

## รอบที่ 1: ฟีเจอร์หลัก

เขียนเทสต์จากไฟล์ตัวอย่างและค่าที่คำนวณมือไว้ก่อน ตอนนั้นโค้ดยังเป็นแค่ฟังก์ชันว่างที่โยน error

```
 × สรุปครบทุกคนในไฟล์ (AC1)
 × ค่าของแต่ละคนตรงกับที่คำนวณมือ (AC2–AC5)
 × เข้างานตรง 08:00 พอดีไม่นับว่าสาย แต่ 08:01 นับว่าสาย (AC4)
 × มีภาพรวม 3 บรรทัด (AC6)
 × สรุปไฟล์เดิมซ้ำได้ผลเหมือนเดิมทุกครั้ง (AC7)
 × อ่านไฟล์ตัวอย่างได้ครบทุกแถว
 × อ่านไฟล์ที่ Excel export มา (มี BOM และขึ้นบรรทัดแบบ CRLF) ได้
 × แจ้งเป็นภาษาไทยเมื่อไฟล์ไม่มีคอลัมน์ที่ต้องใช้

## รอบที่ 2: รองรับไฟล์ CSV หลายแบบ และแถวที่ข้อมูลไม่ครบ

ยังไม่ได้ไฟล์ตัวอย่างจากผู้ประเมิน จึงเขียนเทสต์ครอบรูปแบบที่ไฟล์จาก Excel มักเป็นไว้ก่อน

```
 × ไม่มีเวลาออก: นับเป็นวันทำงาน นับสายได้ แต่ไม่นับชั่วโมง และมีคำเตือน (AC8)
 × ไม่มีเวลาเข้า: นับเป็นวันทำงาน แต่ไม่นับชั่วโมง และมีคำเตือน (AC8)
 × ไม่มีทั้งเวลาเข้าและออก: ไม่นับเป็นวันทำงาน (AC8)
 × เวลาออกก่อนเวลาเข้า: ไม่นับชั่วโมง และมีคำเตือน (AC8)
 × ลงเวลา 2 รอบในวันเดียว: OT คิดจากชั่วโมงรวมของวัน และนับสายครั้งเดียว (AC9)
 × ไฟล์มีข้อมูลเกิน 7 วัน: มีคำเตือน (AC10)
 × อ่านหัวคอลัมน์ภาษาไทยได้
 × ถ้าไม่มีคอลัมน์รหัส ใช้ชื่อแทนรหัส
 × แปลงวันที่แบบ วัน/เดือน/ปี ทั้ง ค.ศ. และ พ.ศ. เป็น YYYY-MM-DD
 × แปลงเวลาหลายรูปแบบเป็น HH:mm
 × อ่านช่องที่มีเครื่องหมายคำพูดและคอมมาข้างในได้
 × แถวที่วันที่อ่านไม่ออกไม่ถูกนับ และมีคำเตือน
 × แจ้งเป็นภาษาไทยเมื่อไฟล์มีแต่หัวคอลัมน์
