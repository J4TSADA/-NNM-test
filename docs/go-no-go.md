## เงื่อนไขที่ถ้าไม่ผ่านข้อเดียว = No Go

- [ ] CI บน PR ผ่านครบ: lint, format, typecheck, test, build
- [ ] เทสต์ทุกข้อใน intent.md (AC1–AC11) เขียว
- [ ] ไม่มีบั๊กระดับ Critical หรือ High ค้างอยู่
- [ ] Deploy ขึ้น Alpha ด้วย tag `v0.1.0` แล้ว และทดสอบบน Alpha ด้วยไฟล์ตัวอย่างผ่าน
- [ ] ทดสอบ rollback บน Alpha แล้วอย่างน้อย 1 รอบ
- [ ] ผู้จัดการตลาด (Product Owner) ยืนยันกติกาเวลาเข้างาน สาย และ OT ใน `src/rules.ts`

## Rollback Plan

แอปเป็นหน้าเว็บ static ไม่มีฐานข้อมูล ไม่มี migration จึงย้อนได้ทันทีโดยไม่เสียข้อมูล

1. ดูว่า tag ก่อนหน้าที่ใช้งานได้คืออะไร: `git tag --sort=-v:refname`
2. deploy tag ก่อนหน้าซ้ำ: `c9n deploy --dry-run` เพื่อดูก่อน แล้ว `c9n deploy` (ตามขั้นตอนใน Deployment Guide ของทีม)
3. เปิดหน้าเว็บ กด "ลองด้วยไฟล์ตัวอย่าง" ตัวเลขต้องตรงกับตารางใน README
4. แจ้งผู้จัดการตลาดว่าย้อนเวอร์ชันแล้ว และเปิด issue บันทึกสาเหตุ

เกณฑ์ตัดสินใจ rollback: หน้าเว็บเปิดไม่ได้ หรือตัวเลขจากไฟล์ตัวอย่างไม่ตรงกับที่ README ระบุ
