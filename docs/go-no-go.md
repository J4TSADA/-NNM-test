## Rollback Plan

แอปเป็นหน้าเว็บ static ไม่มีฐานข้อมูล ไม่มี migration จึงย้อนได้ทันทีโดยไม่เสียข้อมูล

1. ดู tag ก่อนหน้าที่ใช้งานได้: `git tag --sort=-v:refname`
2. GitHub → Actions → workflow **Deploy Alpha** → เลือก run ของ tag ก่อนหน้า → **Re-run all jobs** เว็บจะกลับไปเป็นเวอร์ชันนั้น
3. เปิดหน้าเว็บ กด "ลองด้วยไฟล์ตัวอย่าง" ตัวเลขต้องตรงกับตารางใน README
4. แจ้งผู้จัดการตลาดว่าย้อนเวอร์ชันแล้ว และเปิด issue บันทึกสาเหตุ แล้วแก้ใน PR ใหม่ ก่อน deploy เวอร์ชันถัดไปด้วย `c9n deploy`

เกณฑ์ตัดสินใจ rollback: หน้าเว็บเปิดไม่ได้ หรือตัวเลขจากไฟล์ตัวอย่างไม่ตรงกับตารางใน README
