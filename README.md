# สรุปลงเวลาแม่บ้าน ตลาดหนองเหนียว

อัปโหลดไฟล์ CSV ลงเวลา 1 สัปดาห์ แล้วได้ตารางสรุปต่อคน (วันทำงาน ชั่วโมงรวม มาสาย OT) พร้อมภาพรวม 3 บรรทัด ไม่ต้องสั่ง AI ใหม่ทุกสัปดาห์

## ต้องมีอะไรก่อน

- Node.js 22 ขึ้นไป
- npm

## รันบนเครื่อง

```bash
npm install
npm run dev
```

เปิดลิงก์ที่ขึ้นในเทอร์มินัล แล้วลากไฟล์มาวางในกรอบ คลิกกรอบเพื่อเลือกไฟล์ หรือกด "ลองด้วยไฟล์ตัวอย่าง"

## รูปแบบไฟล์ CSV

ต้องมีคอลัมน์ ชื่อ, วันที่, เวลาเข้า, เวลาออก ส่วนรหัสพนักงานจะมีหรือไม่มีก็ได้ คอลัมน์เรียงสลับกันได้

```csv
employee_id,name,date,clock_in,clock_out
E01,สมใจ,2026-11-23,08:00,16:00
```

| ข้อมูล      | หัวคอลัมน์ที่อ่านได้                                                    | รูปแบบค่าที่อ่านได้                                          |
| --------- | ---------------------------------------------------------------- | ------------------------------------------------------ |
| รหัสพนักงาน | `employee_id`, `emp_id`, `id`, `รหัส`, `รหัสพนักงาน`                | อะไรก็ได้ ถ้าไม่มีคอลัมน์นี้จะใช้ชื่อแทน                           |
| ชื่อ        | `name`, `employee_name`, `ชื่อ`, `ชื่อพนักงาน`, `ชื่อ-สกุล`, `ชื่อ-นามสกุล` | มีคอมมาได้ถ้าครอบด้วย `"..."`                              |
| วันที่       | `date`, `วันที่`                                                    | `2026-11-23`, `23/11/2026`, `23/11/2569`, `23-11-2569` |
| เวลาเข้า   | `clock_in`, `time_in`, `check_in`, `เวลาเข้า`, `เข้างาน`           | `8:05`, `08:05`, `08.05`, `08:05:00`                   |
| เวลาออก   | `clock_out`, `time_out`, `check_out`, `เวลาออก`, `ออกงาน`        | เหมือนเวลาเข้า                                           |

ไฟล์ที่ save จาก Excel (มี BOM หรือขึ้นบรรทัดแบบ Windows) ใช้ได้ ถ้าหัวคอลัมน์ในไฟล์ใช้ชื่ออื่น ให้เพิ่มชื่อนั้นใน `COLUMN_ALIASES` ที่ `src/csv.ts`

แถวที่ข้อมูลไม่ครบหรือผิด เช่น ไม่มีเวลาออก หรือวันที่อ่านไม่ออก จะไม่ถูกนับ และหน้าเว็บจะแสดงกล่องสีเหลืองบอกว่าแถวไหนควรตรวจ

ตัวอย่างเต็มอยู่ที่ `fixtures/sample-week.csv` ผลที่ต้องได้คือ

| ชื่อ   | วันทำงาน | ชั่วโมงรวม | มาสาย | OT  |
| ---- | ------- | -------- | ----- | --- |
| สมใจ | 5       | 43       | 2     | 3   |
| มาลี  | 4       | 33       | 0     | 1   |
| บุญมี  | 5       | 37.5     | 3     | 0.5 |

## กติกาการคำนวณ

อยู่ใน `src/rules.ts` ที่เดียว: เข้างาน 08:00 (หลังจากนั้นนับสาย) และ OT คือชั่วโมงที่เกิน 8 ชั่วโมงต่อวัน กติกาเต็มรวมถึงวิธีจัดการแถวที่ข้อมูลไม่ครบดูใน `intent.md`

## คำสั่ง

| คำสั่ง                   | ทำอะไร                              |
| ---------------------- | ----------------------------------- |
| `npm run dev`          | รันเพื่อพัฒนา                           |
| `npm test`             | รันเทสต์                              |
| `npm run lint`         | ตรวจโค้ดด้วย ESLint                   |
| `npm run format:check` | ตรวจ format ด้วย Prettier            |
| `npm run typecheck`    | ตรวจ type                           |
| `npm run build`        | build ไฟล์ขึ้น production ไว้ใน `dist/` |

## มาตรฐานที่บังคับอัตโนมัติ

- **ก่อน commit:** husky + lint-staged รัน ESLint และ Prettier กับไฟล์ที่แก้
- **ข้อความ commit:** commitlint บังคับรูปแบบ Conventional Commits
- **CI:** `.github/workflows/ci.yml` รัน lint, format, typecheck, test และ build ทุก PR

## Deploy

1. merge PR เข้า `main`
2. สร้าง tag: `git tag v0.1.0 && git push origin v0.1.0`
3. `c9n deploy --dry-run` ดูก่อนว่าจะ deploy อะไร
4. `c9n deploy` ขึ้น Alpha

ก่อนขึ้น production ดู `docs/go-no-go.md`
